# Squint Test

*Source: extracted from `the-edge-wiki/Concepts/Squint Test.md`.*

## What It Is
A visual diversity diagnostic at the ad-account level: **squint at your ad library — does it look visually diverse at a glance, or do all the ads blur into the same image?** Great advertisers pass it; most brands fail it without realising.

## Why It Matters
Persona coverage and vehicle coverage are **not the same problem**. You can have great persona diversity and still have all your ads looking visually identical — that's a vehicle gap, not a persona gap. Under Andromeda / Entity ID dynamics, visual sameness is also an algorithmic penalty: similar opening visuals collapse into the same Entity ID and lose reach.

## Key Facts
- The diagnostic is squint-at-the-library — look for visual sameness vs. distinctness at a glance
- Persona coverage and vehicle coverage are distinct problems — passing one doesn't pass the other
- Visual sameness is an algorithmic penalty under Andromeda: similar openings collapse into one Entity ID
- The pre-launch heuristic *"Would Meta think this looks new?"* operationalizes the test at brief-review time
- Vehicle gaps surfaced by the test feed the Persona x Format Grid for systematic backfill

## How to Apply It
1. Open the brand's Meta Ads Manager creative library (or Ad Library scrape)
2. Squint (or scroll fast / view at thumbnail size)
3. Ask: do these ads look like they're advertising different things, or like 20 versions of the same thing?
4. If the latter → run a vehicle gap analysis the way you'd run a persona gap analysis inside Creative Pillar, and feed the gaps into the Persona x Format Grid

A related pre-launch heuristic: *"Would Meta think this looks new?"* If not, send the brief back.

## Examples
- A brand with "20 versions of the same kitchen scene" fails the Squint Test even with great persona coverage
- 47 Skin's third-person VO with teenager footage was a vehicle-gap fill that would pass a Squint Test against the prior founder-VSL inventory
