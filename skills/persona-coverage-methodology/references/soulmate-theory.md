# Soulmate Theory

*Source: extracted from `the-edge-wiki/Concepts/Soulmate Theory.md`.*

## What It Is
A mental model for AI ad delivery: **there is a perfect ad for every individual user, sitting somewhere in your creative library.** The platform's job is to find that match — but it can only do so if the library has enough *variety* to test against. (Meta internally calls this Soulmate Theory in its Andromeda framing.)

## Why It Matters
This is the mental model that makes Creative Diversity a hard performance lever rather than a soft preference:

- Every new visually distinct creative is an additional "soulmate candidate" the algorithm can pair with a user pocket.
- The more variety, the more matches the algorithm can make.
- More matches → lower CPMs, expanded delivery, incremental reach.
- Conversely, a library of near-identical ads gives Meta nothing to work with — it sees the same "person" over and over.

## Causal Chain
```
More distinct creatives  →  more candidate "soulmates"
                         →  better algorithmic matching
                         →  lower CPMs
                         →  broader unique reach
                         →  more incremental conversions
```

## Implications
- Volume by itself doesn't help if all the ads collapse into the same Entity ID — see Strategic Volume.
- The brief should explicitly target *new persona/setting/format combinations* the library hasn't covered.
- A Squint Test on the ad account: does the inventory look visually diverse at a glance? If not, you have a Soulmate Theory problem.
