# Persona x Format Grid

*Source: extracted from `the-edge-wiki/Frameworks/Persona x Format Grid.md`.*

## The Principle
A pre-launch creative diversification matrix: **N personas × N formats × multiple hook visuals per cell** — the production unit that guarantees both messaging and visual diversity.

## In Plain English
Don't think of creative as "a video here, a static there." Lay it out as a grid. Rows = personas you're targeting (built from review mining, Reddit, post-purchase surveys). Columns = formats (UGC, static, hybrid, etc.). Each cell needs multiple hook visuals and thumbnails. The grid forces you to fill gaps you'd otherwise miss.

## Standard Starting Configuration
- **3 personas × 3 formats** (e.g. UGC, static, hybrid)
- Per cell: **3+ hook visuals, 2+ thumbnails**
- Filled out before launch (Week 0 prep)

## Why It Matters
- Solves both Creative Pillar sub-factor 1 (Persona Coverage) and sub-factor 4 (Format & Vehicle) in one artifact
- Makes the Squint Test passable by construction
- Each cell, properly executed, should earn a distinct Entity ID under Andromeda
- Translates Volume & Velocity math (how many assets / month) into *what* to produce, not just *how many*

## How To Apply
1. Run persona research: market data + customer data + review mining + Reddit
2. Identify 3+ macro personas (micro-personas later)
3. Pick 3+ formats based on what your audiences actually consume
4. For each cell, brief 3+ hook visuals — varying setting, shot type, talent, opening 3 seconds
5. Add a "thumbnail library" column — refresh regularly
6. Pre-launch: run the Squint Test across the grid

## 4-Week Action Plan placement
- **Week 0 — Prep**: Build the grid.
- **Weeks 1–2 — Explore**: Launch 3–5 brand-new concepts (drawn from grid cells), each visually distinct in the first 3 seconds. Test 2–3 message variants inside each.
- **Weeks 3–4 — Exploit**: Take top performers, repurpose across new vehicles/formats. For every strong video, spin out 2 statics + 1 hybrid motion.
- **Ongoing**: Maintain the thumbnail library, refresh regularly. Pre-launch gut check: *"Would Meta think this looks new?"*

## Anti-Patterns
- Treating it as a one-time prep artifact instead of a living dashboard
- Letting one cell dominate (80% of spend on one persona that's 20% saturated = diminishing returns, not a growth lever)
- Filling cells with near-identical creative just to tick the box (collapses to one Entity ID)
