# Creative ID

*Source: extracted from `the-edge-wiki/Concepts/Creative ID.md`.*

## What It Is
Creative ID is **the front-end identifier for an ad asset uploaded in Meta Ads Manager** — what most marketers historically counted when they said "we shipped 50 ads this week." It is not the unit Meta's Andromeda delivery system uses to rank, learn, or attribute reach.

## Why It Matters
Under the post-Andromeda regime, Creative ID is a **vanity count**. The unit that actually drives learning and reach is Entity ID — Meta's *visual fingerprint* of the creative. Two ads can have distinct Creative IDs but share an Entity ID if their opening visuals are too similar, in which case Meta treats them as one ad.

> "You could upload twenty ads that look the same, and Meta would see them as five."

## Key Facts
- Creative ID is the Meta Ads Manager front-end identifier for an uploaded ad asset
- Multiple Creative IDs can collapse to a single Entity ID when opening visuals are too similar
- Creative ID volume is a vanity metric under Andromeda — Entity ID volume is the meaningful one

## Implication
Stop measuring creative output by Creative ID volume. Measure it by **Entity IDs earned** — i.e., how much *visually distinct* output you produced.
