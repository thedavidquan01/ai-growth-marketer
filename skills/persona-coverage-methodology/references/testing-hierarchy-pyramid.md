# Testing Hierarchy Pyramid

*Source: extracted from `the-edge-wiki/Frameworks/Testing Hierarchy Pyramid.md`.*

## The Principle
Map creative tests as a pyramid: **the biggest creative swings sit at the bottom; the smallest refinements sit at the top.** The more visually different a test is, the more likely it earns its own Entity ID — so start at the bottom (big swings) and narrow upward as winners emerge.

## In Plain English
Under Andromeda, small refinements (copy/color/layout changes) don't generate new learning because they don't earn new Entity IDs. So the test program should be biased toward **big-swing variations** — completely new concepts, new vehicles, new personas — and only narrow into refinements once a winning territory is identified.

## The Three Modes

### Exploring (bottom of the pyramid)
- Launch **brand new creative concepts** — not skins of existing winners.
- Test **messaging *within* fresh ads** rather than reusing old visuals — keeps the Entity ID earnings clean and avoids grouping.
- Even when ads end up grouped under the same Entity ID, a winner will still emerge.

### Optimising (middle)
- Once you have a winner, **remix the vehicle**: same story as a podcast clip instead of a UGC video, or as a Reddit-style static instead of a testimonial.
- Give it a **new hook visual** so the first 3 seconds feel different right away.

### Scaling (top)
- **Flip the persona.** Keep the message; change who's saying it or how the first frames look.
- This is what helps the algorithm pair your ad with new audience pockets.

## Effort Split
~50% net-new concepts (Explore) / ~50% big-swing iterations of winners (Optimise + Scale). Tiny message tests live *inside* the new concepts, not as standalone tests.

## How To Apply
1. Allocate roughly 50% of test capacity to Explore-mode (brand-new concepts), 50% to Optimise + Scale
2. In Explore: launch fresh concepts pulled from the Persona x Format Grid — never re-skin existing winners
3. Test message variants *inside* fresh ads, not as standalone copy edits
4. Once a winner emerges, Optimise: remix the vehicle and add a new hook visual
5. Then Scale: flip the persona — keep the message; change who's saying it
6. Audit the test mix monthly — if the pyramid flips top-heavy (mostly micro-tests), reset toward bigger swings

## Anti-Patterns
- **Top-heavy test program** — mostly micro-tests (button colors, headline tweaks). Generates Creative IDs but not Entity IDs.
- **Reusing visuals from old winners for "new" message tests** — the new ads inherit the old Entity ID and lose their fresh-start window.
- **Skipping Explore** — only optimising winners, never adding new concepts. Concentration risk on a few aging Entity IDs.
