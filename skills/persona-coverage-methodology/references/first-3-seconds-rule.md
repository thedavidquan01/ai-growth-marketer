# First 3 Seconds Rule

*Source: extracted from `the-edge-wiki/Concepts/First 3 Seconds Rule.md`.*

## What It Is
An ad's algorithmic classification weight is concentrated in its opening visuals — specifically the first ~3 seconds. If those seconds match an existing ad in the account, the new ad inherits the old Entity ID and starts cold. (Meta's Andromeda system implements this.)

## Why It Matters
Two operational consequences:

1. **The hook visual is the highest-leverage creative variable**, full stop. Changing it is what unlocks new Entity IDs (and therefore new learning, new audiences, fresh reach). Changing copy, headline, or CTA does not.
2. **Production briefs must explicitly diversify hook visuals** — different shot type, persona, setting, format — *before* anything else.

## Key Facts
- Andromeda classifies ads on opening visuals at roughly the first 3 seconds
- Matching opening visuals across ads → inherited Entity ID and cold start
- Hook-visual change unlocks new Entity IDs; copy/headline/CTA changes do not
- Production briefs should explicitly diversify hook visuals before any other variable

## Practical Tactics
- Maintain a running **thumbnail library** and refresh it regularly
- For every winning ad, spin out variants with **net-new hook visuals** (not the same hook with new copy)
- For every shoot, **capture multiple hook options** so post-production can swap them later
- Pre-launch sanity check: *"Does the first 3 seconds look like anything else in this account?"*
