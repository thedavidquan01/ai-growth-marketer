# Creative Strategy (skill hub)

*Source: extracted from `the-edge-wiki/Skills/Creative Strategy.md`. Wikilinks preserved as plain references.*

## What This Skill Is
The ability to design and produce creative that wins across personas, formats, and platforms — treating creative as a *production system* (with diversity matrices and explore/exploit sequencing), not as one-off brand wins.

## When To Use It
- Planning a creative sprint for a paid-acquisition channel
- Briefing a production team or external studio on what to shoot
- Diagnosing why "we ship lots of creative" isn't producing wins
- Mapping persona × format coverage gaps before scaling spend
- Building the creative side of an in-house growth team

## Key Frameworks
- **Creative Pillar** — diagnostic decomposition: persona coverage, messaging diversity, volume & velocity, format & vehicle, concentration & lifespan
- **Creative Diversity** — the 9 dimensions of diversity that earn reach and learning velocity
- **Persona x Format Grid** — 3 personas × 3 formats × multiple hook visuals; the pre-launch matrix
- **Volume & Velocity** — math for production sizing: Win Rate × Half-Life × Churn Rate
- **Testing Hierarchy Pyramid** — explore (net-new concepts) → exploit (iterate winners) → micro-test (headlines/copy)

## Key Concepts
- **First 3 Seconds Rule** — opening visuals carry classification weight; brief and edit accordingly
- **Squint Test** — visual-diversity sanity check at the account level
- **Strategic Volume** — high-volume = high-difference, not high-repetition

## Workflow / How To Apply
1. Build the Persona x Format Grid before any briefs — pre-launch artifact
2. For each cell, brief 3+ hook visuals varying setting/shot/talent/opening
3. Run Squint Test across the grid — would Meta read these as visually different?
4. Sequence production via Testing Hierarchy Pyramid — 50% explore, 50% exploit
5. Capture both video AND statics in the same shoot (production efficiency)
6. Use AI for background swaps and product renders — variation without reshoots
7. Refresh the thumbnail library regularly; treat as a living dashboard not a one-time artifact

## Common Mistakes / Anti-Patterns
- Treating the Persona x Format Grid as a one-time prep artifact instead of a living dashboard
- Letting one cell dominate (80% of spend on one persona that's 20% saturated = diminishing returns)
- Filling cells with near-identical creative just to tick the box — collapses to one Entity ID
- Headline/copy/CTA-only "tests" — fail the Squint Test, earn no fresh reach
- Briefing for "diversity" without operational definition (what dimensions, how measured)
